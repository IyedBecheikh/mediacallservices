# Mediacall Services

A Next.js marketing website for IT services, data processing, web development, telecommunications, and VoIP solutions.

> Status: website prototype. Verify business copy, contact information, and deployment ownership before presenting it as a live client site.

## Site sections

- IT services
- Data processing
- Web development
- Telecommunications
- VoIP services

## Stack

Next.js 15, React 19, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` for static checks.

## Structure

The landing page is composed from reusable components in `src/components/`; page metadata is defined in `src/app/layout.tsx`.
